Política de privacidade do CometPanel

Última atualização: 21 de novembro de 2026

O que é

O CometPanel é um painel pessoal que corre no computador do autor e é usado apenas por ele.

Dados da Google a que acede

  • Google Tasks: ler, criar, marcar como feitas e apagar tarefas, para as mostrar e gerir no painel.
  • Google Calendar (só leitura): ler os próximos eventos, para os mostrar no painel.

Onde ficam os dados

Os dados ficam guardados apenas no computador do utilizador. As autorizações da Google ficam num ficheiro local e as tarefas e eventos só são mostrados no ecrã do painel, na rede de casa. Nada é enviado para servidores do autor ou de terceiros, nem é vendido, partilhado ou usado para publicidade.

Uso limitado

O uso e a transferência de informação recebida das APIs da Google cumprem a Google API Services User Data Policy, incluindo os requisitos de uso limitado.

Remover o acesso

O acesso pode ser retirado a qualquer momento em myaccount.google.com/permissions, ou desligando o Google na página de controlo do painel. Para apagar os dados locais basta apagar a pasta dados do CometPanel.
